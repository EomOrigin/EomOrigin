## 🚀 Projects

**Web demo for tiny object detection in satellite imagery** · capstone design project (TOD team), 2026

<img src="assets/tod-web-demo.gif" alt="Web demo comparing two tiny object detectors on a dense parking scene" width="100%">

Upload a satellite or aerial image and compare our detector with the SMWG-DETR baseline side by side. Large images are tiled at native resolution, and the score threshold and class filters update the result without rerunning.
